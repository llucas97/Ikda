# 읽다 화면 디자인 검토

Impeccable 4.5.1 기준으로 앱 화면을 보았다. 검출기(`detect`)는 Dart 화면에서 기계적 지적을 내지 않았다. Flutter가 이 PC에 없어 기기·브라우저로 화면을 띄우지는 못했다. elayadesign ai-design-skills 는 설치되어 있지 않다.

기준: 먹색 `#1F1D1A`, 종이 `#FFFDF8`, 형광 `#F2C230` 은 밑줄·촬영 버튼·고른 칸만. 글자는 18 이상, 버튼 높이 64, 눌러 보는 영역은 48 이상. 노란 글자는 밝은 바탕에 두지 않는다.

## 나온 문제와 고친 것

| 화면 | 문제 | 고침 |
|---|---|---|
| 로그인 | 아래가 비어 있고, 로고와 글자가 버튼 한쪽에 붙어 있었다. 계정 시트가 흰 카드색이었다. | 가운데에 앱 마크와 서류 그림. 카카오·구글 버튼은 심볼과 글자를 가운데로. 계정 시트 바탕은 종이 `#FFFDF8`. |
| 홈 촬영 | 먹색 버튼에 흰 카메라라 새 아이콘(노란 촬영)과 달랐다. | 촬영 버튼만 노랑 채움, 글자·카메라·스캐너 괄호는 먹색. 다른 큰 면은 노랑으로 칠하지 않는다. |
| 결과 | 금액·날짜가 본문과 같은 먹색이라 형광 밑줄이 없었다. 아래 막대가 카드색이라 화면 바탕과 달랐다. | 강조 숫자에만 노란 밑줄. 글자는 먹색. |
| 가족 목록 | 연결이 없을 때 문장만 있어 그림이 없었다. 연결 끊기가 확인 없이 바로 실행됐다. | 빈 화면에 그림. 끊기 전에 "연결을 끊을까요?" 를 묻는다. |
| 초대 번호 | 56px 숫자가 좁은 화면에서 잘릴 수 있었다. | 칸 너비에 맞춰 줄어들게 했다. |
| 관계 고르기 | 글자 목록이면 어르신에게 작다. | 2열 큰 그림. 고른 칸만 노란 테두리와 옅은 노랑 바탕. 글자는 먹색. |
| 다시 찍기 | 문장만 있으면 무엇이 잘못됐는지 그림이 없다. | 흐림·어두움·반사·작음·잘림 그림을 먹·노랑·종이로 그렸다. |
| 상태 칩 | 급한 일은 빨간 바탕에 종이색 글자. 대비는 약 5.4:1 로 본문 기준을 넘는다. 자주 쓰지 않는다. | 유지. 연한 빨강 위의 글은 `#8E2A1F`. |

## 그대로 둔 것

- 촬영 버튼은 화면에서 가장 큰 노란 면이다. 주인이 촬영 버튼을 노랑으로 정했다. 인사 칸·카드·계정 시트는 종이·카드색이다.
- 스낵바 동작 글자만 노랑이다. 바탕이 먹색이라 대비는 약 10:1 이다. 종이 위의 노란 글자는 없다.
- 관계 후보는 7개다. 한 화면에 고르게 한 것은 주인이 정한 그림 선택이다. 질문은 두 개(부모 쪽 호칭, 자녀 쪽 호칭)로 나뉜다.
- 글자 크기·간격·모서리는 기존 토큰(18–36, 4–48, 8–24)을 그대로 쓴다. 색 이름(`accent` = 먹색)만 바꿔 버튼이 한꺼번에 따라가게 했다.

## 기기에서 다시 볼 것

Flutter analyze 와 실제 화면 캡처는 하지 못했다. 작은 전화기에서 초대 번호, 관계 격자, 로그인 버튼이 한 화면에 들어오는지, 시스템 글자를 1.3배로 키웠을 때 촬영 버튼 글자가 잘리지 않는지 확인이 필요하다.
